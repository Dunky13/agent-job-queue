Apple notarization handoff¶ ↑

Observed on 2026-10-22. This is the evidence record for the Developer ID and notarization change; the signing guide contains the full research, source links, configuration and operator commands.

Implemented behavior¶ ↑

Local development packages remain ad hoc signed. A main-only protected signing job consumes validated universal binaries, imports temporary credentials, and notarizes the payload before signing the enclosing installer. Both app bundles and the final signed DMG receive validated stapled tickets before final hashes and release metadata are generated. Publication also waits for fresh ARM and Intel artifact acceptance jobs. There is no unsigned publication fallback.

Protected CI also retains immutable checkpoints of the signed bytes and Apple submission receipts before and after each upload and after each finite wait. Re-running failed jobs on the original main-push run restores the exact build and continues existing submission IDs. The default wait is five minutes per stage. A pending submission blocks publication without losing the build. Run, repository, source, team, version and archive hashes are checked before resuming. Unknown upload outcomes and missing or expired state fail closed. The signing guide documents recovery commands and the 30-day retention boundary.

New casks keep quarantine and directly run the signed Go controller. The native installer uses the same Go entry. The companion tap update must merge before the source change. Historical paired cask/manifest records are preserved until a newer source release is published; generated Casks/ files are unchanged.

Issues found during validation¶ ↑

The real signing test caught a missing = prefix on a literal codesign requirement before any upload. The command and stub regression now enforce macOS's literal-versus-file requirement syntax.

Race testing exposed a nominal five-second cleanup loop that could exceed its budget under scheduling delay. A deterministic delayed-poll fixture reproduced the original failure; elapsed-time cleanup passes with the original test deadline unchanged.

The real Homebrew fixture showed that a quarantined unsigned shell-script entry can be killed by macOS. New casks and the native installer directly enter the signed Go controller. Review also required ownership of Homebrew's separate installer process groups before private fixture tools can be removed.

That review finding is closed: the fixture tracks Homebrew's separate command groups, bounds cancellation and inherited output waits, and retains private tools if cleanup cannot be proven. Real Homebrew regressions cover timeout, normal parent exit with a surviving child, and outer cancellation. Independent Sol 6.1 high review of the final source found no remaining actionable issues.

The latest pre-change main run passed all required validation but failed publication because checkout cleaned the previously downloaded dist assets. The signing change puts checkout before downloads and adds a workflow regression. That prior release was not published successfully.

The first final notarized Homebrew test copied only the payload into an otherwise incomplete Agent Job Queue Installer.app directory. macOS blocked its signed controller in dyld before Go started. Copying the complete signed and stapled installer instead made the same real Homebrew install finish in 11 seconds, with the original 60-second deadline and quarantine preserved on every staged entry. The fixture now checks the enclosing installer before and after staging, and rejects the former incomplete enclosure before execution. No backend change, quarantine removal or deadline increase was needed.

The new checkpoint mode test initially assumed creating a file with mode 0755 would override a private process umask. Reproduction showed the fixture was already 0700 before snapshotting and remained 0700 after restore. The test now explicitly establishes and checks 0755 before transfer, then requires the same mode and attribute afterward. It passes under both 022 and 077 umasks and race detection; the broad race suite subsequently passed.

Independent review caught that the new opt-in incomplete-installer regression was excluded by the final artifact job's exact test selector. Both hosted architectures now run all TestNotarizedHomebrew cases with the finalized payload. Workflow lint passed, and independent Sol 6.1 high re-review found no remaining actionable findings in this repair. Cross-provider review was not available and is not claimed.
